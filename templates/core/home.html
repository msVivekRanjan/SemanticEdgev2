Core Architecture

The definitive NVR architecture for privacy-first automation — detection, tracking, logging, and live streaming all in one open-source system.

01 / Detection

Reduce false positives

YOLOv8 runs on every frame and filters to target object classes, so motion events are evaluated against real edge AI — not crude pixel diffs. Even on CPU, processing stays under 30ms per frame.

02 / Tracking

Persistent identity

ByteTrack assigns a unique ID to every detected object across frames. Trajectories are drawn in real time, so you can see the exact path a person walked, or trace how a vehicle moved through the scene.

> Analyzing stream... [✓] Frame 1024 captured [✓] Object detected: person #3 [✓] Confidence: 91% [✓] Trajectory: 28 points Processing time: 18ms

03 / Logging

Structured event log

Every detection is stored with timestamp, frame number, track ID, class, confidence, bounding box coordinates, and single snapshot evidence — strictly accessible only to the owning user.
