Capabilities

The definitive NVR architecture for privacy-first automation — detection, tracking, logging, and live streaming all in one open-source system.

01 / Detection

Reduce false positives

YOLOv8 runs on every frame and filters to six critical COCO object classes, so motion events are evaluated against real edge AI — not crude pixel diffs. Even on CPU, processing stays under 30ms per frame.

02 / Tracking

Persistent identity

ByteTrack assigns a unique ID to every detected object across frames. Trajectories are drawn in real time, so you can see the exact path a person walked, or trace how a vehicle moved through the scene.

03 / Logging

Structured event log

Every detection is appended to a structured CSV log with timestamp, frame number, track ID, class, confidence, bounding box coordinates, and line-crossing status — ready for analytics or alerting pipelines.

Architecture

How it works

01

Detect

YOLOv8 runs inference on every captured frame, returning bounding boxes and class labels filtered to the six target COCO classes.

02

Track

ByteTrack assigns and maintains unique IDs across frames, even through brief occlusions. Trajectory history (last 30 points) is drawn on the frame.

03

Log

Every detection event is appended to a structured CSV log with full metadata — timestamps, coordinates, class, confidence, and line-crossing status.

04

View

Django streams annotated JPEG frames to your browser via MJPEG-over-HTTP — no video library, no WebRTC complexity. The stats panel updates in real time.
